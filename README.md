# ถังรวม — Data Storytelling Dashboard

**รายวิชา Business Idea Creation**

Dashboard เชิงเล่าเรื่องของบริษัท **ถังรวม (ชื่อชั่วคราว)** ระบบหลังร้านสำหรับร้านแก๊ส LPG ที่ขายหลายแบรนด์
เล่าผ่านข้อมูล 6 เดือนของร้านแก๊ส 1 ร้านที่ขาย 4 แบรนด์ ว่าทำไมร้านแบบนี้จึงต้องการระบบของเรา

**เปิดดู Dashboard:** ดับเบิลคลิก `dashboard/index.html` (ไฟล์เดียว ไม่ต้องติดตั้งอะไร ไม่ต้องต่ออินเทอร์เน็ต)

---

## หัวข้อใน Dashboard

1. ภาพรวมตลาด LPG (ข้อมูลจริง)
2. ยอดขายแยกแบรนด์
3. ออเดอร์รายวันและช่วงเวลา
4. ถังที่อยู่กับลูกค้า และลูกค้าที่ยังไม่คืนถังเปล่า
5. ลูกค้าที่หยุดสั่งแต่ยังถือถังของร้าน
6. ลูกหนี้แยกตามอายุหนี้
7. สรุป

เลือกแบรนด์ได้จากเมนูด้านบน (ยกเว้นข้อ 1)

---|---|---|
| 1 ตลาด | ร้านกี่ % ที่ไม่มีแอปจากเจ้าของแบรนด์ | **ข้อมูลจริง** ส่วนแบ่งตลาด Q2/2568 |
| 2 สี่แบรนด์ | แอปของแบรนด์เดียวเห็นธุรกิจร้านได้แค่ไหน | จำลอง |
| 3 งานรายวัน | ร้านรับออเดอร์วันละเท่าไหร่ ช่วงไหนยุ่ง | จำลอง |
| 4 ถังนอกร้าน | ถังอยู่กับลูกค้ากี่ใบ ใบไหนไม่มีมัดจำคุ้มครอง | จำลอง |
| 5 ถังหลับ | ลูกค้าคนไหนเงียบไปพร้อมถังของร้าน | จำลอง |
| 6 เงินค้าง | ลูกหนี้ค้างนานแค่ไหน ควรทวงใครก่อน | จำลอง |
| 7 ทางออก | ระบบสรุปงานที่ต้องทำพรุ่งนี้ + สิ่งที่ยังต้องพิสูจน์ | — |

บทที่ 3–6 กรองตามแบรนด์ได้จากแถบด้านบน

## ข้อมูลที่ใช้ — อ่านก่อนนำเสนอ

**ค้น Kaggle และแหล่งข้อมูลเปิดแล้ว ไม่พบข้อมูลระดับรายการขายของร้านแก๊ส**
(พบเพียงราคาแก๊สและทะเบียนผู้ค้าในต่างประเทศ เช่น ฮ่องกง จอร์แดน อินเดีย ชิลี)
จึง **สร้างข้อมูลจำลอง (synthetic data)** ขึ้นจากพฤติกรรมของธุรกิจ

| ไฟล์ | ประเภท | คำอธิบาย |
|---|---|---|
| `data/reference/market_share_lpg_q2_2568.csv` | **จริง** | ส่วนแบ่งตลาด LPG ของกรมธุรกิจพลังงาน Q2/2568 อ้างใน [รายงาน LH Bank ต.ค. 2568](https://www.lhbank.co.th/getattachment/031004c9-34dc-4c54-b374-4928bb44246c/economic-analysis-Industry-Outlook-2025-Natural-Gas_Oct_2025) · แถว "อื่น ๆ" = 100 − ผลรวม |
| `data/raw/customers.csv` | จำลอง | ลูกค้า 220 ราย (บ้าน / ร้านอาหาร / รถเข็น) ชื่อสมมติทั้งหมด |
| `data/raw/transactions.csv` | จำลอง | รายการแลกถัง ซื้อถังใหม่ คืนถัง 2,344 รายการ |
| `data/raw/payments.csv` | จำลอง | การชำระเงินของลูกค้าเครดิต |
| `data/raw/products.csv` | สมมติฐาน | ราคาแก๊สและมูลค่าถังโดยประมาณ ไม่ใช่ราคาประกาศ |
| `data/raw/brands.csv` | สมมติฐาน | สัดส่วนแบรนด์ในร้านตัวอย่าง |

**ไฟล์สำหรับส่ง:** `data/ข้อมูลที่ใช้_ถังรวม.xlsx` รวมทุกตารางไว้ในไฟล์เดียว พร้อมชีตอธิบายและชีตสรุปตัวเลข (สร้างใหม่ได้ด้วย `python scripts/export_excel.py`)

ความหมายของทุกคอลัมน์อยู่ใน [`data/DATA_DICTIONARY.md`](data/DATA_DICTIONARY.md)

**ข้อจำกัด:** ตัวเลขบทที่ 2–6 แสดง *รูปแบบ* ของปัญหา ไม่ใช่ขนาดของปัญหาในร้านจริง
และยังไม่ได้ยืนยันว่าร้านแก๊สยอมจ่ายค่าระบบเดือนละเท่าไหร่

## สร้างข้อมูลและ Dashboard ใหม่

ต้องการแค่ Python 3.8+ (ไม่ต้องติดตั้งไลบรารีเพิ่ม)

```bash
python scripts/generate_data.py     # สร้าง data/raw/*.csv (seed คงที่ ได้ผลเดิมทุกครั้ง)
python scripts/build_dashboard.py   # ฝังข้อมูลลง dashboard/index.html
```

ปรับสมมติฐาน (จำนวนลูกค้า สัดส่วนแบรนด์ ราคา อัตราลูกค้าเลิกซื้อ) ได้ที่ส่วนบนของ `scripts/generate_data.py`
แก้ชื่อสมาชิกที่ `team.csv` แล้วรัน `build_dashboard.py` ใหม่
