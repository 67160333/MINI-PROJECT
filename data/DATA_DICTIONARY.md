# Data Dictionary

ช่วงข้อมูล 2026-04-01 ถึง 2026-09-30 (1 เม.ย. – 30 ก.ย. 2569) · ร้านตัวอย่าง 1 ร้าน · ข้อมูลจำลอง ยกเว้นที่ระบุ

## customers.csv
| คอลัมน์ | ความหมาย |
|---|---|
| customer_id | รหัสลูกค้า C001… |
| name | ชื่อสมมติ + พื้นที่ |
| segment | `household` บ้าน · `restaurant` ร้านอาหาร · `vendor` รถเข็น/แผงลอย |
| brand | แบรนด์ถังที่ลูกค้าใช้ (`WP` เวิลด์แก๊ส · `PTT` ปตท. · `UNQ` ยูนิคแก๊ส · `SGP` สยามแก๊ส) — ลูกค้าแลกได้เฉพาะยี่ห้อเดิม |
| size_kg | ขนาดถัง 4 / 15 / 48 กก. |
| cylinders_at_start | ถังที่ลูกค้าถืออยู่ ณ 1 เม.ย. 2569 (0 = ลูกค้าใหม่) |
| first_seen | วันที่เริ่มซื้อ (ลูกค้าเดิม = "ก่อน 2026-04-01") |
| credit_customer | `Y` ซื้อเชื่อจ่ายรอบเดือน |

## transactions.csv
| คอลัมน์ | ความหมาย |
|---|---|
| txn_id, date, time | รหัส วันที่ เวลา |
| customer_id, brand, size_kg | ลูกค้าและชนิดถัง |
| txn_type | `exchange` แลกถังปกติ · `new_cylinder` ซื้อถังใหม่ (วางมัดจำ) · `return_cylinder` คืนถังรับมัดจำคืน |
| full_out | จำนวนถังเต็มที่ส่งออก |
| empty_in | จำนวนถังเปล่าที่ได้คืน (น้อยกว่า full_out = ลูกค้ายังไม่คืนถัง) |
| gas_amount | ค่าแก๊ส (บาท) |
| deposit_amount | ค่ามัดจำถัง (บวก = รับ · ลบ = คืนให้ลูกค้า) |
| payment_method | `cash` · `transfer` · `credit` (ยังไม่จ่าย) |
| paid_amount | เงินที่ได้รับ ณ วันทำรายการ |
| channel | `phone` · `line` · `walk_in` |
| delivery | `delivery` ไปส่ง · `pickup` รับที่ร้าน |
| driver | คนส่ง |

**ยอดถังที่ลูกค้าถือ** = cylinders_at_start + Σ(full_out − empty_in)
**ถังเกินมัดจำ** = ยอดถังที่ถือ − (cylinders_at_start + ถังที่ซื้อใหม่ − ถังที่คืน)

## payments.csv
การชำระเงินของลูกค้าเครดิต: payment_id, date, customer_id, amount, method
ยอดค้าง = Σ gas_amount ที่เป็น credit − Σ amount · อายุหนี้คิดแบบ FIFO (เงินที่จ่ายตัดบิลเก่าสุดก่อน)

## products.csv (สมมติฐาน)
size_kg, gas_price (ราคาขายแก๊สต่อถัง), cylinder_value (มูลค่าถัง/ค่ามัดจำ) — ค่าประมาณ ไม่ใช่ราคาประกาศ

## brands.csv (สมมติฐาน)
brand, brand_th, share_in_shop (สัดส่วนลูกค้าของแต่ละแบรนด์ในร้านนี้)

## reference/market_share_lpg_q2_2568.csv (ข้อมูลจริง)
ส่วนแบ่งตลาด LPG ไตรมาส 2/2568 ของกรมธุรกิจพลังงาน อ้างในรายงาน LH Bank (ต.ค. 2568)
แถว OTHERS คำนวณจาก 100 − ผลรวม 5 รายแรก
